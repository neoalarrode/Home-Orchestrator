Puente de ingesta para bombillas Govee — LAN local como vía principal, con la API Cloud oficial de Govee como respaldo para lo que LAN no alcanza (modelos sin soporte, o sin la "LAN API" activada) — consumidas internamente por Lighting y/o expuestas a Home Assistant por MQTT.

Antes de escanear

Cada bombilla necesita la "Govee LAN API" activada A MANO en la app oficial de Govee (ajuste por dispositivo, dentro de los ajustes de cada uno) — sin eso, no responde aquí ni aunque esté en la misma red. No hace falta ninguna cuenta ni contraseña: en cuanto está activada, la IP en la LAN basta.

Cuenta Cloud (respaldo)

API key gratuita de developer-api.govee.com (se pide desde la app oficial: Perfil → Configuración → Acerca de nosotros). Solo hace falta para los dispositivos que LAN no puede alcanzar — nunca se usa como vía principal si LAN ya responde.
